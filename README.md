# Expense Tracker

A clean and intuitive **Django-based Expense Tracker** designed to help
you **track, manage, and analyze your spending** with a simple UI and
powerful insights.

------------------------------------------------------------------------

## What this app does

This app allows you to:

-   💸 Track your daily expenses
-   🏷️ Categorize spending (food, travel, etc.)
-   ✏️ Edit or delete entries easily
-   📊 Visualize spending with charts (donut + trends)
-   🔍 Filter and explore past transactions
-   📈 Analyze spending over time (7 days, month, year)

-   Backend: Django\
-   Frontend: HTML + PicoCSS\
-   Charts: Chart.js\
-   Database: SQLite

------------------------------------------------------------------------

## 🚀 How to Run

``` bash
git clone https://github.com/preetam-g/expense-tracker.git
cd ExpenseTracker

python -m venv venv
source venv/bin/activate   # mac/linux
venv\Scripts\activate    # windows

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open: [https://expense-tracker-kq6l.onrender.com](https://expense-tracker-kq6l.onrender.com)
